## 2. 我为什么没按「方案 A」发 0.2.1

**因为新安装包内部的版本号仍然是 `0.2.0`。**

我核对了新包的文件版本资源：

```
文件                              RAINBOWMC-0.2.0-setup.exe
大小                              81,852,306 字节  ✅ 与你给的一致
sha256                            ea0136d6…572f16  ✅ 与你给的一致
FileVersion (资源)                0.2.0      ← 关键
ProductVersion (资源)             0.2.0      ← 关键
```

`electron-builder` 会把 `package.json` 的 `version` 写进 exe 的版本资源，
而 `app/package.json` 现在还是 **`0.2.0`**（我 02:25 打的包就是 0.2.0）。

**如果按方案 A 发布成 `0.2.1 / code 21`，会发生这个死循环：**

```
① 客户端本地 0.1.0(10) → 接口说 0.2.1(21) → 提示更新
② 下载 → 校验通过（sha256 对得上）→ 安装
③ 装完启动 → app.getVersion() 读 exe 资源 = 0.2.0 → versionCode = 20
④ 再次检查 → 接口说 0.2.1(21) > 本地 0.2.0(20) → 又提示更新
⑤ 无限循环，且每次都要重下 78 MB
```

**所以方案 A 成立的前提是：新包必须用 `version: "0.2.1"` 重新构建。**
你文档里也写了「客户端：我看到发布结果后，把 package.json 提到 0.2.1 重新出包（下次构建）」——
但那意味着**现在这个包不能当 0.2.1 发**。

**我选了方案 B：保持 `0.2.0 / 20`，替换文件与哈希。** 这样内部版本和接口版本一致，不会循环。

## 3. 但我没有原地覆盖 —— 换了文件名

### 3.1 原因：Cloudflare 会把这个 exe 缓存 4 小时

我第一次是**原地覆盖**的，替换后实测响应头：

```
HTTP/2 200
content-type: application/octet-stream
content-length: 81852306
cf-cache-status: EXPIRED        ← 说明 CF 缓存过
cache-control: max-age=14400, must-revalidate    ← 4 小时
```

我 nginx 里写的是 `add_header Cache-Control "no-cache, must-revalidate";`，
但**被 Cloudflare 覆盖成了 `max-age=14400`**。

**后果**：原地覆盖后，最长 4 小时内客户端可能仍下到**旧文件**，
而接口已经返回**新 sha256** → 必然校验失败。

我没有 Cloudflare API Token，刷不了缓存（你文档 §6 那条命令需要 `<ZONE_ID>` 和 `<TOKEN>`）。

### 3.2 改用带构建号的文件名

```
旧：RAINBOWMC-0.2.0-setup.exe        （被 CF 缓存了，现在库里已不指向它）
新：RAINBOWMC-0.2.0-setup-r2.exe     ← 接口现在返回这个
```

新 URL 是全新的，CF 没有缓存：

```
HTTP/2 200
content-length: 81852306
content-type: application/octet-stream
accept-ranges: bytes
cf-cache-status: MISS      ← 未命中缓存，直接从源站取
```

**这个做法以后每次替换都用**：文件名加 `-r2` / `-r3`，不用碰 Cloudflare 后台。

## 8. 给你的两条长期建议

**① 以后每次替换发布包，文件名都加构建号**

```
RAINBOWMC-0.2.0-setup-r2.exe
RAINBOWMC-0.2.0-setup-r3.exe
```

不然会被 Cloudflare 的 4 小时缓存咬到。**这是比我刷缓存更可靠的办法**。

**② 想彻底关掉这个缓存**

在 Cloudflare 后台 → Caching → Cache Rules 里加一条：

```
URL 匹配  https://rainbowdoor.icu/launcher/*
设置      Cache Eligibility = Bypass cache
```

我没有后台权限，你要是能进去就顺手加一下，以后就不用管文件名了。
