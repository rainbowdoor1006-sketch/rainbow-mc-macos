# 社团网站授权接口约定（RAINBOW MC 启动器 ↔ 社团网站）

> 这份文档是给社团网站那边实现的参考。启动器侧已经写好了调用逻辑，你只要让接口返回约定的 JSON，启动器就能用。

## 1. 请求

```
POST {baseUrl}{authPath}
Content-Type: application/json
```

默认配置（可在启动器「设置 → 社团授权接口」里改）：

- `baseUrl`：例如 `https://club.rainbowdoor.cn`
- `authPath`：例如 `/api/launcher/authorize`
- 合起来就是 `https://club.rainbowdoor.cn/api/launcher/authorize`

请求体：

```json
{
  "username": "社团账号",
  "password": "密码",
  "launcher": "RAINBOW MC",
  "launcherVersion": "0.1.0"
}
```

## 2. 成功响应（HTTP 200）

```json
{
  "ok": true,
  "token": "可选，后续接口鉴权用",
  "user": {
    "id": "u_123",
    "name": "鸽子",
    "avatar": "https://club.rainbowdoor.cn/avatar/u_123.png"
  }
}
```

- `user.id` 必填：启动器用它绑定离线账号，同一个社团账号换设备也能认出是同一个人
- `user.name` 必填：显示在启动器账号卡片上
- `avatar` 可选
- `token` 可选：以后要做「社团网站查战绩/封禁/在线人数」时用

## 3. 失败响应

HTTP 200 或 4xx 都可以，**只要 body 是下面这个结构**：

```json
{
  "ok": false,
  "code": "INVALID_CREDENTIALS",
  "message": "账号或密码错误"
}
```

建议的错误码：

| code | 含义 | 启动器展示 |
|---|---|---|
| `INVALID_CREDENTIALS` | 账号或密码错 | 直接显示 message |
| `ACCOUNT_BANNED` | 账号被封禁 | 直接显示 message |
| `NEED_VERIFY` | 需要先验证邮箱/手机 | 直接显示 message |
| `RATE_LIMITED` | 请求太频繁 | 直接显示 message |
| `SERVER_ERROR` | 服务端错误 | 直接显示 message |

启动器会把 `message` 原样展示给用户，所以 message 请写成中文人话。

## 4. 安全建议

1. **必须 HTTPS**，启动器只发 HTTPS 请求（http 也能发但不建议）
2. 密码建议在服务端用 bcrypt/argon2 存储，不要存明文
3. 建议加频率限制（同一 IP / 同一账号 5 次/分钟）
4. 建议记录登录日志（时间、IP、启动器版本），方便排查盗号
5. 如果以后要防「一个社团账号给多人用」，可以在响应里加个设备指纹字段，启动器可以配合上报

## 5. 启动器侧行为

| 场景 | 行为 |
|---|---|
| 设置里 `mockMode = true`（默认） | 不请求网络，随便填都通过，用于接口没做好之前联调 |
| `mockMode = false` | 走真实 HTTP 请求，失败就提示错误，不生成离线账号 |
| 离线登录 | 必须先过社团授权，再填游戏内昵称，两步都过才建账号 |
| 正版登录 | 不需要社团授权（微软已经验证过身份） |

## 6. 联调步骤

1. 社团网站把接口做出来，用 Postman / curl 测通
2. 启动器「设置 → 社团授权接口」：填 baseUrl、authPath，把「本地模拟模式」关掉
3. 点左侧「离线登录」→ 填社团账号密码 + 游戏昵称 → 登录
4. 如果报错，错误码会直接显示（`E9006` 不是 JSON、`E9007` 缺字段、`E9008` 连不上）

## 7. 用 curl 自测

```bash
curl -X POST https://club.rainbowdoor.cn/api/launcher/authorize \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"test\",\"password\":\"123456\",\"launcher\":\"RAINBOW MC\",\"launcherVersion\":\"0.1.0\"}"
```

期望返回：

```json
{"ok": true, "user": {"id": "u_123", "name": "鸽子"}}
```
