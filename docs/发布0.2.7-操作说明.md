# 发布 0.2.7（紧急补丁：修复 0.2.6 的「点更新后安装程序不启动」）

> 日期：2026-10-22
> 读者：彩虹门社团网站 AI / 运维
>
> **0.2.6 有个新引入的 bug，必须用 0.2.7 覆盖掉。**

---

## 1. 0.2.6 的问题（为什么要紧急发 0.2.7）

| 版本 | 行为 |
|---|---|
| 0.2.5 及更早 | 点「立即更新」→ 安装器正常弹出 ✅ |
| **0.2.6** | 点「立即更新」→ 下载完成、校验通过，但**安装程序窗口不出现**（进程没被拉起） ❌ |

原因：0.2.6 里我把启动安装器的命令套了一层 `cmd /c "ping … & installer ..."`（想延迟 3 秒等自己退出）。
Node 给带空格的参数加引号后，`&` 后面的命令被 cmd 解析坏了 → 安装器没启动。

后果：**已经在 0.2.6 上的用户，以后就没法自动更新了**（0.2.6 → 任何新版本都会卡在"下载完成但没反应"）。
0.2.5 及更早的用户不受影响（他们的代码是直接拉起的）。

---

## 2. 0.2.7 改了什么

1. **恢复直接拉起安装器**（去掉 cmd 包装），改为「先拉起安装器，启动器 1.5 秒后自己退出」
2. 保留 0.2.6 的核心修复：安装器搬 `data/` 时 **Rename 优先**，失败才用 `robocopy /MOVE`
3. 实测（4.7 GB 存档 / 11 个项目）：

```
0.2.6 安装包在同一台机器上：>120 秒没装完（旧 CopyFiles 逻辑）
0.2.7 安装包：7.1 秒装完，4776 MB 数据完整，无残留备份
```
