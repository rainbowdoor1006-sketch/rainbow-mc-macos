# 升级路径全面测试报告（老版本 → 新版本）

> 测试日期：2026-10-31　被测安装包：0.2.71（老）/ 0.2.85（新）
> 测试方式：把真实安装（6.5 GB，含 3 个项目 / 4 个账号 / 存档）**完整克隆**到 `D:\Temp\RM-UPG-TEST`，
> 在克隆体上做升级/卸载/跨目录实验；真实目录的 data 全程只读、未改动。
> 结论先写：**同目录升级安全，data 一个字节没少；但「跨目录安装」会误删原安装的程序文件——必须改。**

## 二、核心结论：同目录升级是安全的

升级前后对 `data/` 做的结构快照对比：

```
data 子目录（文件数）
  assets 3589 · avatars 1 · backgrounds 1 · cache 594 · exports 1
  games 8123 · libraries 202 · library 1 · logs 74 · runtime 327 · tools 5 · versions 16
差异：无

关键文件哈希（config.json + 4 个 level.dat）
差异：无

项目：香草纪元 / 七七·完整离线包 / 12张地图跑酷文明   一致
账号：4 → 4
```

**这验证了 `customRemoveFiles` 的设计是对的**：只删 `$INSTDIR` 顶层的
`*.exe/*.dll/*.pak/*.dat/*.bin/*.json/*.txt/*.html/*.ico/*.yml` + `resources/` + `locales/`，
**绝不 RMDir /r $INSTDIR**，所以 `data/` 物理上不会被删。

## 三、发现的严重问题：跨目录安装会误删原安装程序文件

### 复现步骤

1. 注册表 `Uninstall\RAINBOW MC\InstallLocation` 指向 **A 目录**（真实安装）
2. 执行 `RAINBOWMC-0.2.85-setup.exe /S /KEEPDATA /D=B目录`
3. 结果：
   - **A 目录的 `RAINBOW MC.exe` 等程序文件被删除**（data 保留）
   - B 目录只创建了一个空文件夹，安装被 Abort
   - 结论：**两头空——原安装废了，新位置也没装成**
4. 附带后果：`Uninstall` 键被清空到只剩 `InstallLocation`，系统「应用和功能」里看不到、卸不掉

### 根因

`installer.nsh` 的 `customInit` 只比对了 `InstallLocation` 与 `$INSTDIR`，不一致就 `MessageBox + Abort`。
但 **NSIS 在 `customInit` 之前已经执行了「旧版本卸载器」**（electron-builder 模板行为），
旧卸载器按注册表里的路径删除程序文件 → 删除发生在保护逻辑之前。

另外：**静默安装 `/S` 下 `MessageBox` 不显示**，用户完全看不到提示，只会发现"装了一下，应用没了"。

### 与 2026-10-26 那次事故完全同源

当时把测试版装到 `D:\Temp\RM-*`，结果用户的 `D:\APP\RAINBOWMC\RAINBOW MC.exe` 被删——
本次测试复现了同一机制（真实目录程序文件被删、data 未丢）。

## 四、给你下一步「更新机制改动」的建议

按优先级：

| 优先级 | 改动 | 说明 |
|---|---|---|
| P0 | **安装前先校验目标目录**，不一致时**在启动旧卸载器之前**就 Abort | 需要把判断从 `customInit` 前移到 electron-builder 的 `preInit`，或用 `!if` 改成先检查再让模板执行卸载 |
| P0 | **自动更新一律不传 `/D`**（或只传当前 `installRoot()` 且先与此前注册值比对） | 用户目录统一时就不会触发跨目录 |
| P0 | 更新失败时**不要静默**：把 Abort 原因写进 `data\logs\update.log` 并弹一次提示 | `/S` 下 MessageBox 无效，要改成写日志 + 应用内提示 |
| P1 | 安装/更新前**自动备份 `Uninstall` 注册表项**，失败可还原 | 防止出现"只剩 InstallLocation"的坏状态 |
| P1 | 卸载项每次安装后**重写全部字段**（DisplayName/Icon/UninstallString/QuietUninstallString） | 现在只写 `InstallLocation`，被清空后无法卸载 |
| P2 | 升级完成后**自动校验**：程序版本、data 存在性、项目数、账号数，异常则提示 | 可把本报告的检查项做成启动器自检 |
