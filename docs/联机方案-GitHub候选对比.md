## 三、结论

**不换方案。** 现在用的 Terracotta 已经是这批候选里唯一同时满足「开源免费 + 国内可用 + 零配置」的：

- 用户只填一个邀请码（`U/XXXX-XXXX-XXXX-XXXX`），二进制我们自己下载
- 底层是 EasyTier（14.3k 星、LGPL、周更），走 P2P；打洞失败才回落中继
- 大整合包实测可用（566 模组的《侏罗纪》）

**要提升的地方不是换方案，而是加一层自建中继**（见下）。

### 不建议的

| 方案 | 为什么不建议 |
|---|---|
| e4mc | 中继在海外，国内延迟高；还要玩家装 mod，整合包再加 mod 容易冲突 |
| ZeroTier / NetBird / tailscale 系 | 必须装客户端 + 账号/网络 ID，普通用户直接劝退；国内官方节点慢 |
| FRP 类 | 免费带宽只有 1~10 Mbps，566 模组的区块同步会卡成 PPT；还要实名签到 |
| MCTier | 方向对（EasyTier 套壳），但协议未标注、生态小，可作为**备选通道**观察，不做默认 |

## 四、可落地的三个优化（不换方案）

### 1. 自建 EasyTier 中继节点（收益最大）

```
在 rainbowdoor.icu 服务器上跑 EasyTier，作为 relay/公共节点
→ P2P 打洞失败时不再挤公共中继，速度与稳定性由自己控制
→ 成本：一台国内小机器（1核1G 足够，中继只转发不转码）
```

### 2. 大整合包的传输参数调优

| 参数 | 现状 | 建议 |
|---|---|---|
| MTU | 默认 | 降到 1300~1380，减少分片丢包（大包尤为明显） |
| 传输协议 | TCP/UDP 自动 | 强制 UDP 优先，弱网时开 KCP 加速 |
| 中继策略 | 公共节点 | 优先自建节点，公共节点仅兜底 |

### 3. 房主侧「一键优化」开关

联机页加一个「为大整合包优化」勾选，勾上后自动：
- 调 MTU、开 UDP 优先
- 提示房主关闭「渲染距离 32 区块」这类上传压力大的设置
