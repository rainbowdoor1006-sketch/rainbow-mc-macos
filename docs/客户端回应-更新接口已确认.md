### 关键实测：覆盖安装不丢存档

```
① 安装到 D:\Temp\RAINBOWMC-test
② 写入 D:\Temp\RAINBOWMC-test\data\games\test-save\level.dat
③ 再次运行同一个 setup.exe（静默覆盖安装）
④ 结果：level.dat 仍在，内容一致；临时备份目录已自动清理
```

> 实现方式：安装前把 `data/` 重命名到「安装目录同级」的 `*-data-backup`，
> 装完再还原。因为 electron-builder 的 NSIS 覆盖安装会先跑旧卸载程序，直接清空 `$INSTDIR`。

### 数据目录位置

```
<安装目录>/
└── data/                    ← 存档、模组、组件库、日志全在这里
    ├── config.json
    ├── games/               ← Minecraft 项目（存档）
    ├── versions/ assets/ libraries/ runtime/
    ├── logs/                ← 启动日志
    ├── cache/               ← 下载缓存与更新包
    └── backgrounds/
```

安装程序会自动创建这些目录；老用户的 `%APPDATA%\RAINBOWMC` 会在首次启动时自动迁移进来。
