## 这版包含的修复

| # | 问题 |
|---|---|
| 1 | 配置被写坏时项目/账号全丢 → 现在 `config.json.bak` + 损坏自动回退 |
| 2 | 数据目录从 `%APPDATA%` 搬到安装目录后，背景/头像的旧绝对路径失效 → 启动时自动改写 |
| 3 | 微软登录会把自定义头像覆盖成皮肤地址 → 现在保留本地头像 |
| 4 | 新建配置默认 `client_id` 为空导致无法登录 → 默认改为公开 client_id（public 模式） |
| 5 | 更新弹窗「当前版本」显示 exe 版本而非比较版本 → 已修 |
