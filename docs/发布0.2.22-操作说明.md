## 4. 这版做了什么

| 项 | 内容 |
|---|---|
| **CurseForge 整合包** | 以前只能导入 `.mrpack`；CF 包（manifest.json 只有 projectID/fileID）导入后 0 个模组。现在会按 ID 解析并下载全部模组 |
| 免 Key 通道 | `api.cfwidget.com/{projectId}` 查文件名 → `mediafilez.forgecdn.net/files/{id/1000}/{id%1000}/{name}` 直链下载 |
| 回退顺序 | 免 Key → 社团代理（可选）→ 自备 Key（可选） |
| 设置页 | 新增「CurseForge 整合包」卡片：代理地址（默认 `https://rainbowdoor.icu/api/cf`）、自己的 API Key（可留空） |

**实测**：`Ice and Fire-3.0.zip`（CF 包，1.20.1 + Forge 47.2.0）

```
→ 31 个模组全部下载成功（96.1 MB，jar 头均为 PK）
→ 自动补齐 62 个游戏库
→ 项目可直接启动
```

## 5. 关于 CF 代理接口（你之前那份文档）

**现在变成可选了。** 免 Key 通道已可用，实测能完整导入。
如果你们愿意做 `/api/cf/file` 代理（服务端持 Key），会更稳定、不依赖第三方接口；不做也不影响功能。

客户端设置里已经预留了地址，默认 `https://rainbowdoor.icu/api/cf`，接口上线后自动生效。
