RAINBOW MC
开源 Minecraft 启动器 · Electron + React · MIT
装上就能玩，不用配 Java、不用手动装加载器
 
▪ 一键安装加载器：Forge / NeoForge / Fabric / Quilt，自动补齐依赖

▪ 启动前体检：估算内存 / 显存 / CPU 负载，还能给模组做静态检查
