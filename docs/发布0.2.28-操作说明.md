## 4. 从 0.2.22 到 0.2.28 改了什么

| 版本 | 内容 |
|---|---|
| 0.2.23 | 曾尝试加 `-Dfml.earlyprogresswindow=false`（后证实该属性在 Forge 47.x 不存在，已撤） |
| 0.2.24 | 安装器加硬保护：**装到与现有安装不同的目录时直接中止**，避免把另一份安装的程序文件删掉（实测原来会删） |
| 0.2.25 | 崩溃诊断升级：遇到显卡崩溃时列出本机显卡、点名虚拟显示器 |
| 0.2.26 | **Forge/NeoForge 启动前自动写 `config/fml.toml` 的 `earlyWindowControl = false`**，解决 `nvoglv64.dll` 启动崩溃 |
| 0.2.27 | ① 启动分 5 阶段打点（带毫秒）② 崩溃自动追加「启动诊断」块 ③ 崩溃后自动登记高性能 GPU + 自动禁用渲染优化模组 |
| **0.2.28** | **新增 `ensureAssets()`：自动下载游戏资源（语言/声音/字体），启动前与整合包导入后各补一次** |

### 关键：0.2.28 修了什么用户可见问题

- 游戏能进、但**语言列表空白、没有声音** → assets 从未下载，本版自动补齐（1.20.1 约 500 MB，首次启动会显示进度）
- Forge 整合包**启动即崩**（`nvoglv64.dll`）→ 自动关闭早期窗口
- CurseForge 整合包导入后**一个模组都没有** → 免 Key 通道按 ID 下载（0.2.22 起）
