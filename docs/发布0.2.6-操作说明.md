## 4. 这一版修了什么

| 问题 | 原因 | 修复 |
|---|---|---|
| **升级时安装界面卡在进度条一半** | 安装器搬迁 `data/`（存档、组件库、游戏版本、加载器）时，因为启动器还占着文件，改名失败后逐个文件复制 4.7 GB | ① 客户端更新前先退出启动器，延迟 3 秒再拉起安装器 ② 安装脚本改为 `Rename` 优先，失败才用 `robocopy /MOVE` |
| 附带 | — | 语言默认繁體、许可页中文、`/D` 参数、卸载保留数据 等均已包含 |

**实测对比**（同一台机器、4.7 GB 存档 / 11 个项目）：

```
0.2.5：卡死（3 分钟以上无进展）
0.2.6：7.6 秒完成，11 个项目 / 4776 MB 数据完整，无残留备份
```
